# Source map

## Applied curation, 2026-09-06

[UCC model section 2-102](https://www.law.cornell.edu/ucc/2/2-102) was inspected as a concrete source scope example: transaction type affects which legal rules apply. Adopt explicit document, jurisdiction, transaction and precedence boundaries. Do not treat model UCC text as every jurisdiction's enactment or as authority over all software and service agreements. Exact quotations and defined terms are protected from prose style rewrites. Refresh within 90 days; qualified applicable law review remains separate from factual extraction.

`contract-analysis` is an individually authored V5 skill package; empirical qualification is tracked separately in the audit/evaluation ledger. These maintained sources bound factual and version-sensitive guidance; qualification is tested with hierarchy-aware held-out routing, paired same-model skill/no-skill tasks, and independent blind evaluation.

## Qualification basis

- Hierarchy: broader reference-communication.
- Routing: five positive, five near-neighbor negative, three compound/ambiguous, and three adversarial held-out cases through the real resolver.
- Full-task evaluation: two individual scenarios with six falsifiable checks, same-model skill/no-skill pairing, regression retention, and blind semantic judging.
- Source discipline: authoritative/spec/reference sources outrank community patterns when they conflict; runtime evidence outranks examples for behavioral claims.

## Interpretation rules

- Prefer the primary official/spec/reference source over community conventions when they conflict.
- Resolve the actual product, language, runtime, provider, platform, protocol, or standard version before applying details that can drift.
- Treat examples as examples, not proof that the current repository/runtime behaves the same way.
- Preserve unknowns and source conflicts explicitly; do not merge incompatible guidance into a false universal rule.
- Keep operational checks in the real target environment whenever the claim depends on runtime behavior.
