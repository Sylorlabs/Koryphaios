# Contributors

Koryphaios is built in public by people and agent-assisted workflows that care
about capable local software, provider choice, reversible changes, and evidence
before claims.

## Project stewardship

- [@micahcooley](https://github.com/micahcooley) — creator and maintainer

## Agent-assisted and automated contributions

Koryphaios keeps automated work visible instead of presenting it as anonymous
human authorship. The repository history currently includes contributions from:

- [@claude](https://github.com/claude)
- [Google Labs Jules](https://github.com/apps/google-labs-jules)
- [@actions-user](https://github.com/actions-user)

Every contribution remains subject to the same review, testing, and evidence
standards regardless of whether it was written by a person, an agent, or both.

## Contribute

Open an [issue](https://github.com/Sylorlabs/Koryphaios/issues) for a concrete
problem or proposal. Pull requests should explain the user impact, keep unrelated
changes out of scope, and include the checks that support the result.

Contributors are credited from the repository history. If your contribution is
missing or attributed incorrectly, open an issue so the record can be corrected.
